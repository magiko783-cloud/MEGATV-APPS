# MEGA TV — تجهيز GitHub ثم Cloudflare (لم يُنشر بعد)

## 1. ارفع ملفات واجهة المتجر إلى GitHub
- أنشئ **مستودعًا جديدًا** باسم `MEGATV-APPS` (يفضل Public لو التحميل لجميع الزوار).
- فك ضغط `MEGATV_GitHub_Ready.zip` وارفع ملفات الواجهة (`index.html`, `apps.json`, `images/`, `_headers`, `link_releases.py`) إلى المستودع. **لا ترفع APK بداخل Git العادي**.
- المستودع العام يسمح بالتحميل لجميع الزوار؛ لا تضع كلمات مرور أو بيانات اشتراك في الملفات.

## 2. ارفع التطبيقات التسعة مستقلة في GitHub Releases
- افتح المستودع > **Releases** > **Draft a new release**.
- اختر Tag جديد `v1` وعنوان `MEGA TV APK Collection v1`.
- اسحب **كل ملف APK من الملفات التسعة المرفقة بالمحادثة بشكل منفصل** إلى خانة Attach binaries (لا ترفع ZIP واحدًا بدل التسعة).
- تأكد من ظهور التسعة بنفس أسمائها المكتوبة في `apps.json` (مسافات وأحرف كبيرة و+ مهمة).
- اضغط Publish release. هذه الخطوة تنشر ملفات التحميل للعامة إن كان المستودع عامًا، **لكنها لا تنشر المتجر على Cloudflare**.

## 3. اربط الروابط تلقائيًا
- على كمبيوتر عليه Python: افتح مجلد الواجهة وشغّل:
  `python link_releases.py USERNAME MEGATV-APPS v1`
  واستبدل `USERNAME` باسم حساب GitHub الحقيقي. سيملأ `downloadUrl` لكل تطبيق في `apps.json`.
- اختبر رابطَي تحميل على الأقل في المتصفح قبل النشر. أكواد Downloader ستظل فارغة حتى يتم إنشاؤها والتحقق منها فعليًا.
- حدّث ملف `apps.json` في المستودع بعد تشغيل السكربت.

## 4. لاحقًا: Cloudflare Pages
- اربط مستودع GitHub بخدمة Cloudflare Pages مع إعداد Static site دون أمر build؛ مجلد النشر هو `/`.
- أو ارفع محتويات مجلد الواجهة مباشرةً إلى Pages عند الموافقة على النشر.
- لا تنشر المتجر إلا بعد اختبار صور التطبيقات والتقسيم وروابط التحميل والتأكد من وجود تطبيق FLIX القديم إذا أردت إدراجه.

## ملاحظات مهمة
- **عدد التطبيقات الحالية: 9**، جميعها منفصلة، حتى نسختا RED+ ونسخ FLIX المختلفة.
- **FLIX القديم الموجود بالفعل على متجرك السابق غير موجود ضمن هذه الملفات التسعة**؛ نحتاج رابطه وصورته الصحيحة لإضافته دون تخمين.
- إن غُيّر اسم أي ملف APK عند رفعه إلى Releases، يجب تعديل `filename` في `apps.json` قبل تشغيل السكربت.
- احرص على أن تكون التطبيقات المرفوعة ملكك أو لديك حق توزيعها. GitHub قد يقيّد استخدام Releases كخدمة توزيع عامة مخالفة لشروطه.
